# AI / ML Full-Stack Portfolio

Production-oriented portfolio projects spanning classical machine learning, retrieval-augmented generation, and time-series forecasting.

## Projects

### 1. Customer Churn Classification Platform
End-to-end classification service with feature preprocessing, model training, probability-based risk scoring, FastAPI APIs, responsive frontend, Docker support, tests, and reproducible metrics.

### 2. Enterprise RAG Knowledge Assistant
Retrieval-augmented generation application with document ingestion, chunking, semantic retrieval, grounded answers with citations, optional LLM generation, retrieval evaluation, FastAPI, frontend UI, Docker, and tests.

### 3. Retail Demand Forecasting Platform
Demand forecasting application with lag, rolling, calendar, and promotion features, time-based validation, recursive multi-day forecasting, FastAPI APIs, interactive dashboard, Docker, and tests.
